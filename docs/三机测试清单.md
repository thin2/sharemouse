# 多设备测试清单

测试设备可命名为 Mac、Win-A、Win-B；先关闭其他键鼠共享软件。三台使用兼容的 v7 构建，主设备点击“显示连接 IP”，其他两台填写双方共同网络中的主设备 IP，在两端确认后自动交换成员和地址，布局按实体方向配置。先以可丢弃文字、透明 PNG、JPEG、动图 GIF、空文件、带中文/空格名称的文件夹测试。系统权限、杀毒提示和防火墙按安装说明处理。

下表每行记录“通过 / 失败 / 未测”、设备方向和简短现象。应用内图片粘贴与文件管理器粘贴分别记录。

| 场景 | 操作与预期 |
| --- | --- |
| 安装与启动 | 干净机器无需开发工具可打开，授权后可共享；窗口主题和中英文切换可保存 |
| IP 加入 | 两端确认后连接；任一端取消不得授权；第三台仅填主 IP；重启恢复；主设备撤销成员后重启不恢复授权 |
| 多网卡与热点 | 以太网、Wi-Fi 和热点地址显示完整；选择共同网络地址可加入；地址重复与组已满提示不同 |
| 设备与布局 | 添加/编辑/删除设备，拖动方向，重启后保存；状态明确显示主设备与当前目标 |
| 三台选主 | 分别以三台为主；先全员停止再换主；一台离线时禁止接管 |
| 键鼠 | 四个方向切屏、快速往返、按住修饰键/鼠标键切屏、滚轮；Command 保留 Mac 原生行为 |
| 文本跟随 | A 复制 X → B 粘贴 → C 粘贴仍为 X；B 复制 Y → C 得 Y；重复复制同文也产生新记录 |
| 暂停与重启 | 停止共享不改其他设备剪贴板；恢复按规则取最新主动复制；启动不覆盖原剪贴板 |
| 图片应用粘贴 | 截图、浏览器图片、图片软件内容，分别在聊天/文档应用粘贴，PNG 透明度正确 |
| 图片文件粘贴 | Finder/Explorer 复制单张 PNG/JPEG/GIF，在两系统文件管理器粘贴成文件，核对散列和 GIF 动画原件 |
| 未支持内容 | 多图/超限/混合文件应显示未支持，不误用前一张图；同步中等准备完成后再粘贴 |
| 无历史记录 | 本机复制和远端同步均不生成历史文件；旧版历史不读取、不修改；重启不覆盖系统剪贴板 |
| 消息 | 文字/链接指定设备收到，收发方向正确；不改任何设备剪贴板；兼容接收旧版图片消息 |
| 关闭与退出 | 关闭窗口继续收消息，托盘/菜单栏打开仍在；真正退出后消息清空、按键释放 |
| 默认自启 | 登录后隐藏启动，重复打开只有一份界面/后台；关闭设置后再次登录不启动；升级不重复注册 |
| 文件/文件夹 | 三个方向互传，窗口拖拽及 Finder/Explorer 右键，中文/空格、多选图片、空目录/文件均正确 |
| 重名 | Ask 弹窗覆盖/跳过/改名分别验证；覆盖目录合并且保留接收端独有文件 |
| 断网与休眠 | 活跃输入时断开网络/休眠；无卡住键，恢复重新确认会话；传输失败可手动重发 |
| 并发 | 接收接近 1 GB 文件时持续切屏、输入、复制图片；记录延迟/丢键/停顿及传输耗时 |
| 升级与卸载 | 共享中升级能正常停止；自启开/关偏好保存；卸载移除入口和注册，收到文件保留 |

每个数据场景覆盖 Mac→Win-A、Win-A→Mac、Win-A→Win-B，并轮换主设备和鼠标目标。静态透明图记录目标应用名称及版本；GIF 文件用 SHA-256 确认原件，应用不播放动画不能直接判定原件丢失。

## 记录性能

真实三机先测空闲，再传大文件并重复相同动作。记录系统版本、CPU、网络连接方式、文件大小/散列、总耗时、十次切屏/停止确认耗时、是否丢键或出现卡住修饰键。当前没有锁定跨设备延迟合格阈值，请保留原始数值和主观可用性。

开发机的 python3 tests/performance_session_smoke.py 只测同机三个进程、真实 TLS、dummy 输入。它输出 .local/performance-baseline.json；包含控制轮次的观察吞吐，不能当作局域网速度或真实键鼠延迟。已有单元测试及 smoke 通过也不能替代表中场景。

## 报告问题

每个问题包含：构建 build.json 的 commit/modified、三台系统版本、主设备和目标、复现步骤、预期和实际、必现或偶发。可截图界面状态，隐藏不相关资料。

可选生成只含系统/二进制散列/端口/后端及设备数量的诊断 JSON（Python 3.11+）：

```sh
python3 scripts/collect-diagnostics.py \
  --binary "/Applications/Sharemouse.app/Contents/MacOS/lan-mouse" \
  --output diagnostics-mac.json
```

Windows 使用对应 exe 路径；需要统计配置时显式添加 --config。工具不采集剪贴板、消息、文件名、证书或私钥。输出文件已存在时拒绝覆盖。无需发送配置目录、历史库或证书。

本清单作为通用测试模板保留。实际测试记录和诊断文件只保存在本地；
提交问题时仅提供必要且已脱敏的复现信息，任何未执行项标记为未测。
